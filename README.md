# Personal Finance Playground

Mobile-first, free, standalone financial *what-if* simulator. Built with a single `index.html` using HTML, CSS, and JavaScript. No account, backend, or paid hosting required.

**Live site:** https://getnkit.github.io/personal-finance-playground/

## Simulators

- **Investment & Retirement:** monthly contributions, compound growth, and illustrative withdrawals
- **Car Timing:** costs of buying a car earlier than planned
- **Savings & Goals:** savings targets, pauses, and **Car Fund vs Investing** comparison
- **Financial Benchmark:** personal savings metrics and a clearly dated Thai statistics snapshot

## Hosting and updates

GitHub Pages serves `index.html` from the `main` branch at the repository root. Commit changes to that file to trigger a new deployment. Follow deployment status under **Actions**.

Calculations run locally in your browser. The example inputs are **not** actual financial records. No personal financial data is stored or sent to a server by the app. Benchmark statistics are snapshots, **not** live data, and require evidence-based updates. All results are hypothetical, not guaranteed returns or financial advice.
